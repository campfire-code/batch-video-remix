# 批量混剪工厂

> 篝火出品 · 收录于篝火 App 应用区

素材按「开头 / 中段 / 结尾」分组，随机抽取片段、随机截取时长，一次拼出几十条电商短视频。全程在本机用内置 ffmpeg 处理，不联网。

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/batch-video-remix/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `batch-video-remix_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `batch-video-remix_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `batch-video-remix_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

1. **准备素材**：建三个文件夹，名字里带「开头」「中段」「结尾」（也认「片头」「片尾」「intro」「outro」等）。放进各自的视频，把整个素材文件夹（或三个子文件夹）拖进窗口。不在开头/结尾文件夹里的视频都算「中段」，所以只有一堆素材、不分组也能用，但至少要有 1 个中段素材。
2. **设定生成**：生成条数、每条目标时长、片段最短/最长（每个片段在这个范围内随机取时长，起点也随机）。
3. **画幅与清晰度**：竖版 9:16、方形 1:1、横版 16:9，720p 或 1080p。素材比例不一致时铺满画面、多出的部分裁掉。
4. **声音**：可保留素材原声（没有音轨的素材自动补静音），可叠加一个本机的背景音乐并调音量；音乐比成片长会截取并在结尾淡出，短则循环。请确认你对该音乐有使用权。
5. **字幕（可选）**：每行写一条文案，选「按顺序」或「随机」取法和位置，每条成片取一句整段显示。字幕在应用里画成透明图片再叠加，用的是系统自带中文字体，不打包字体文件。
6. **随机种子（可选）**：填同样的种子 + 同样的素材和参数，会得到同样的组合；留空每次不同。每次完成后提示里会写本次用的种子。
7. 点「开始处理」，在保存目录得到 `混剪-日期-时间-序号.mp4`（H.264 + AAC，无声时没有音轨）。

**去重**：同一批里「用了哪些素材、什么顺序」不会重复。组合数不够时（例如只有 3 个中段素材、每条要 3 个片段，只有 6 种排法），只生成能生成的条数并提示；可增加素材、缩短每条时长或加大片段时长。

**每条的结构**：1 个开头片段（有开头素材时）+ 若干中段片段（数量 = 目标时长 ÷ 平均片段时长，四舍五入，至少 1 个，同一条里中段素材不重复）+ 1 个结尾片段（有结尾素材时）。

不使用大模型，设置页里没有接口配置。

## 验收用例

示例素材由 `node scripts/make-samples.mjs` 生成（ffmpeg 合成的色块/几何动画，无版权问题）：`samples/开头/`（2 段）、`samples/中段/`（5 段，其中 1 段无音轨）、`samples/结尾/`（2 段），另有 `samples/示例-背景音乐.wav`。素材比例有竖版、横版、方形，用来检验统一画幅。

| 操作 | 应得到的结果 |
|---|---|
| 把 `samples/` 里三个文件夹一起拖入；条数 5、每条 15 秒、片段 2-4 秒、9:16、1080p、关闭保留原声，开始处理 | 列表里每段素材显示分组和时长（`示例-中段5-无音轨` 另标「无音轨」）；输出目录得到 5 个 MP4，均为 1080x1920、约 15 秒、无音轨；5 条的素材组合互不相同，每条第一段来自「开头」、最后一段来自「结尾」 |
| 同上，种子填 `123`，再来一次（新的输出目录） | 两次的组合和每个片段的起点、时长完全一致 |
| 打开「保留素材原声」，音乐选 `samples/示例-背景音乐.wav`，音量 50% | 成片有 AAC 音轨，原声和音乐混合；音乐只有 8 秒，会循环补满并在最后 2 秒淡出；中段5 没有音轨也不报错 |
| 字幕文案填两行（如 `示例：今天下单立减 10 元` / `示例：库存有限，先到先得`），位置靠下，取法按顺序 | 第 1、3、5 条显示第一句，第 2、4 条显示第二句，白字半透明底；输出目录里没有残留的「字幕层」PNG |
| 画幅改 1:1、720p | 输出 720x720 |
| 只拖入 `开头1`、`结尾1` 和 3 段中段，条数填 20，每条 15 秒、片段 2-4 秒 | 只生成 6 条（3 个中段取 3 个的排法 = 6 种），并提示「素材组合数只有 6 种，不足 20 条」 |
| 拖入一个 .png 文件 | 不会被加入列表，提示「不是支持的视频格式」 |

开发者可用 `C05_REAL=1 pnpm exec vitest run src/tool/real.test.ts` 在本机用真实 ffmpeg 和 samples/ 跑一遍，核对分辨率、时长、音轨并完整解码。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
